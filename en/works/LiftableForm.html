LiftableForm

  • Arduino
  • Processing
  • Servo Motor
  • PWM Control
  • Rack-and-pinion Mechanism
  • Multi-link Mechanism
  • Pin Display
  • Shape-changing Interface
  • 9-axis IMU Sensor
  • 3D Printing

LiftableForm is a handheld pin-based shape-changing interface. It explores how portability can change the way users interact with physical shape displays.

Many conventional pin-based shape-changing displays are fixed to a desk or floor, making it difficult to incorporate actions such as lifting the device, pressing it against an object, or changing its orientation.

By giving a shape-changing interface portability, this project aims to treat bodily actions such as holding, moving, rotating, and pressing the device as part of the interaction.

LiftableForm individually controls a 5 x 10 array of pins using servo motors, presenting information as physical height differences. The pin heights can be perceived visually and also through touch.

The prototype investigates mechanisms and interaction possibilities for portable shape-changing interfaces, including object holding, pressing, and gesture-based manipulation.
