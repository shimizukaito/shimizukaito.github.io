# 現行行ドライバ

外付けAE-PCA9685のPWM0～10 → J12 → TBD62783APG×3 → ポンプ11台。
U1は0～3、U2は4～7、U3は8～10。1～8が入力、9が保護後12V、10がGND、18～11が対応出力。
未使用入力はGND、未使用出力は無接続。ソース型でプラス側を切替。
J1～J11はJST B2B-XH-A、1番スイッチ＋・2番GND。J12は1×12・2.54mmヘッダー。J13はWJ142Vの2極4脚。
F1/F2/F3=MF-R185、C1=470µF/25V、C2/C3/C4=0.1µF/50V、2.54mmピッチ。C2/C3/C4は各ICの電源端子近傍。
100×50mm、1.6mm、2層、1oz指定。出力0.8mm、12V幹線2mm、両面GNDベタでパッド直結。
4つの取付穴は3.2mm非メッキ。基板側にケーブルタイ用の長穴はありません。筐体側で張力止めを設けます。
試験・電気的制限・出典はmanufacturing/jlcpcb/設計レビュー.mdを参照。

## Rev.Dの電源配線
J13の1番（2脚とも）= +12V_RAW。C1の＋もこの入力側、－はGND。
- +12V_RAW → F1の2番 → F1の1番/+12V_U1 → U1の9番、C2の1番。
- +12V_RAW → F2の2番 → F2の1番/+12V_U2 → U2の9番、C3の1番。
- +12V_RAW → F3の2番 → F3の1番/+12V_U3 → U3の9番、C4の1番。
F1～F3はMF-R185。部品自体に極性はありません。3つの保護後電源を互いに接続しないこと。
U1～U3の10番、C2～C4の2番、J13の2番（2脚とも）はGND。
共通MF-R300は廃止。入力幹線とC1はこれらPTCより手前なので、電源側の過電流保護が別途必要です。
